Detection signals

Six ways an attacker gives themselves away

Each signal adds weight to a 0 to 100 risk score. No single rule decides; the combination does.

SIG-01geo

Impossible travel

Chennai at 09:02, Frankfurt at 09:40. We compute the travel speed between consecutive logins and flag anything a plane can't do.

velocity > 900 km/h → +35
SIG-02device

Unknown device fingerprint

Browser, OS, screen, fonts and WebGL hashed into a stable fingerprint. A brand new one on a long-lived account raises the score.

first_seen = now → +20
SIG-03volume

Credential stuffing

Bursts of failed passwords across many usernames from one IP range. Trailock rate-limits the source before a valid combo lands.

fails/5min ≥ 8 → +4 each
SIG-04network

Risky network & ASN

Tor exit nodes, open proxies, VPN ranges and hosting ASNs are scored against a reputation feed refreshed hourly.

asn_type = hosting → +18
SIG-05behaviour

Off-pattern hours

Each user builds a baseline of when they normally sign in. A 3 AM login from someone who works 9 to 6 stands out.

z-score > 2.5 → +12
SIG-06mfa

MFA fatigue

Repeated push prompts in a short window usually mean someone is spamming approvals, hoping the user taps yes to make it stop.

pushes/10min ≥ 4 → +25

Three steps from install to protected

Works alongside Auth0, Cognito, Keycloak or your own login form.

01 / collect

Drop in the SDK

A 9 KB script gathers device and session signals on your login page. No cookies, no PII stored in raw form.

02 / score

Ask before you let in

Your backend sends the login event. Trailock replies with a score, the reasons, and a recommended action.

03 / respond

Allow, challenge or block

Low risk passes silently, medium triggers step-up MFA, high gets blocked and posted to Slack or your SIEM.

// server.js — score a login before issuing a session
const verdict = await trailock.assess({
  user: "priya@acme.io",
  ip: req.ip,
  fingerprint: req.body.trailockToken,
  outcome: "password_ok"
});

// → { score: 82, action: "block", reasons: ["impossible_travel", "risky_asn"] }
if (verdict.action === "block")     return res.status(403).end();
if (verdict.action === "challenge") return requireMfa(res);
createSession(res);
